# 🌍 Travel Website

A simple and responsive travel website built using HTML and CSS.  
The website allows users to explore hotels, restaurants, and flight information through easy navigation using anchor tags.

## ✨ Features

- 🏨 Hotels page  
- 🍽️ Restaurants page  
- ✈️ Flights page  
- 🔗 Easy navigation using anchor tags  
- 📱 Responsive design  
- 🎨 Clean and simple user interface  

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Anchor tags for page navigation  

## 📄 Pages

| Page | Description |
|---|---|
| Home | Main landing page of the website |
| Hotels | Shows hotel options and details |
| Restaurants | Shows restaurant options and details |
| Flights | Shows flight information and booking details |

## 🔗 Navigation

The website uses HTML anchor tags to move between pages:

```html
<a href="index.html">Home</a>
<a href="hotels.html">Hotels</a>
<a href="restaurants.html">Restaurants</a>
<a href="flights.html">Flights</a>
```

## 🚀 How to Run

1. Download or clone this repository:

```bash
git clone [https://github.com/your-username/travel-website.git](https://github.com/your-username/travel-website.git)
```

2. Open the project folder.

3. Open `index.html` in any web browser.
